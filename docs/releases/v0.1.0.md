# llm-evalboard v0.1.0: Statistically Honest LLM Evaluation

> Answers one question reliably: *"Is this prompt or model change a real improvement, or just noise?"*

We are proud to announce the initial production-ready release of **`llm-evalboard`** (v0.1.0), an open-source, statistically rigorous LLM evaluation framework and web dashboard designed to eliminate subjectivity, flakiness, and false confidence when deploying LLM applications.

---

## 🌟 Key Highlights & Innovations

### 1. The Statistical Engine (`@evalboard/stats`)
- **Paired Cluster Bootstrap Confidence Intervals:** Isolates the treatment effect across identical inputs and stochastic repeats ($R \ge 3$).
- **Equivalence Margin Testing ($\pm\delta$):** Distinguishes between practically meaningful improvements and trivial noise within an indifference band.
- **Actionable 4-Way Verdicts:** Replaces ambiguous pass rates with:
  - 🟢 **`BETTER`**: Lower bound $L > 0$ and point estimate $d \ge +\delta$.
  - 🔴 **`WORSE`**: Upper bound $U < 0$ and point estimate $d \le -\delta$.
  - 🔵 **`NO MEANINGFUL DIFFERENCE`**: True difference is bounded strictly within $[-\delta, +\delta]$.
  - 🟡 **`INCONCLUSIVE`**: Computes the exact additional sample size needed to achieve 80% power at $\alpha = 0.05$.
- **Pareto Frontier Under Uncertainty:** Evaluates probabilistic Pareto dominance across Cost vs. Quality and Latency vs. Quality.

### 2. Structural Reproducibility & Content-Addressed Caching (`@evalboard/core`, `@evalboard/providers`)
- Every prompt template, dataset row, grader configuration, and evaluation matrix cell is content-addressed via SHA-256 canonical JSON representations.
- **$0 Re-runs:** Unchanged cells return instantly from cache at \$0 cost.

### 3. Calibrated LLM Judges (`@evalboard/graders`)
- **Position-Swap Bias Mitigation:** Evaluates pairwise comparisons in parallel as both $(A, B)$ and $(B, A)$ to eliminate position-1 bias.
- **Inter-Annotator Agreement (Calibration Engine):** Calculates weighted Cohen's $\kappa$ against human ground truth.
- **Visible Trust Badges:** `TRUSTED` ($\kappa \ge 0.70$), `USE WITH CAUTION` ($0.40 \le \kappa < 0.70$), `NOT TRUSTED` ($\kappa < 0.40$), and `UNCALIBRATED`.

### 4. Production-to-Test Flywheel (`@evalboard/flywheel`)
- Continuous ingestion of production traces with negative user feedback.
- Multi-stage PII scrubbing (emails, phone numbers, IPs, bearer tokens, AWS/GitHub keys, credit cards via Luhn check, high-entropy secrets via Shannon entropy).
- MinHash / Jaccard deduplication, synthetic variation generation, and 1-click test suite promotion.

### 5. Security & Red-Teaming (`@evalboard/redteam`)
- Built-in adversarial probes across the OWASP Top 10 for LLMs.
- Multi-turn adaptive attacker loop with jailbreak framing and refusal suppression.
- Wilson score Attack Success Rate (ASR) with asymmetric 95% confidence intervals.

### 6. Promptfoo Drop-in Interoperability & Shadow Runner (`@evalboard/promptfoo-compat`)
- Drop-in compatibility with `promptfooconfig.yaml` and assertion mapping matrix.
- **Shadow Mode (`evalboard promptfoo shadow`):** Evaluates existing Promptfoo suites across stochastic repeats to detect single-run **"False Passes"**.
- Bidirectional export back to `promptfooconfig.yaml`.

### 7. Continuous Integration & Observability (`@evalboard/action`)
- GitHub Action CI runner enforcing statistical merge gating (`fail-on-regression`, `fail-on-inconclusive`).
- Sticky PR comment bot with ASCII Forest Plots, Core Metrics table, and Slice Analysis.
- Telemetry export to OpenTelemetry (GenAI semantic conventions) and Langfuse.

### 8. Web Dashboard (`apps/web`)
- Next.js 15 App Router with Tailwind CSS, Server Components, and Recharts Pareto scatter plot.
- Strict WCAG 2.1 AA accessibility (color is never the sole carrier of meaning).
